# Schetsen: verband tussen de modi

Open de HTML-bestanden in een browser (ook op je telefoon). Ze gebruiken `../concepts/engine.js` voor de theorie en de klank, en `modi.js` voor bruggen en routes. De analyse staat in [../../modi-analyse.md](../../modi-analyse.md).

- [d-in-app.html](d-in-app.html): **het voorstel**. Het nieuwe paneel "Modi en bruggen" in het huidige werkblad, op de plek van de modale kaart, met de CSS van de app.
- [a-rooster.html](a-rooster.html): alle 84 modi. Rijen hebben dezelfde noten, diagonalen dezelfde grondtoon.
- [b-brugmatrix.html](b-brugmatrix.html): één grondtoon, met een balk per akkoord over de modi waarin het voorkomt.
- [c-route.html](c-route.html): de kortste route van modus naar modus, met per stap de brug en de sprong.

Screenshots staan in [shots/](shots/).
